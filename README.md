# Medlake Training — Website Redesign

A full redesign of Medlake Training Küsnacht — a Swiss medical fitness centre. Built as a freelance project with a focus on cinematic design, smooth 3D animations, a complete content management system, and automatic multilingual support.

> Freelance project — client cancelled before launch.

**Live demo:** [medlake.vercel.app](https://medlake.vercel.app) &nbsp;|&nbsp; **Stack:** Nuxt 3 · Three.js · Tailwind CSS · Supabase · DeepL

---

## What it looks like

The design is inspired by [heimdallpower.com](https://www.heimdallpower.com/) — full black background, oversized typography, editorial grid layouts, and a cinematic hero section powered by Three.js.

### Key interactions

- **Hero** — On first scroll the camera zooms in from a distant view of floating 3D photo cards to a close-up carousel. Arrow buttons and dot indicators switch between slides. Scroll back to the top to zoom out.
- **Dark / Light mode** — Toggleable from the nav. Preference saved across sessions.
- **Services accordion** — Each service expands inline with a description and a link to its dedicated page.
- **Gallery lightbox** — Click any photo to open a full-screen lightbox with keyboard navigation.
- **Scroll animations** — Every section fades and slides in as it enters the viewport.

## Multilingual — DE · EN · FR · IT

The site supports four languages out of the box — German (default), English, French and Italian — with a language switcher in the navigation.

All translations are handled automatically via a **DeepL API pipeline**:

- **Static content** (nav labels, UI strings, page headings) lives in locale JSON files per language. New languages are generated by running a single script that calls DeepL and writes the output files automatically.
- **Dynamic content** (news posts, team bios, service descriptions, opening hours) stored in Supabase is translated on demand via a `/api/translate-record` endpoint. Translations are cached back into the database so DeepL is only called once per record.
- **Admin panel** — when a staff member creates or edits a record in the CMS, translations are triggered automatically in the background. No manual copy-pasting into different language fields.

Adding a new language takes a single command — DeepL handles the rest.

## Admin Panel

The site ships with a built-in CMS at `/admin`. No third-party CMS needed.

**News** — Write and publish posts with a title, tag, cover image and rich HTML content. Toggle between draft and published. Posts appear on the home page and `/news` automatically — and are translated into all active languages via DeepL.

**Team** — Add team members with a name, role, sort order and photo. Photos are uploaded directly to Supabase Storage.

**Ärzte** — Manage doctor profiles independently — name, specialty, photo, biography and direct phone number.

**Galerie** — Upload multiple photos at once with captions. Appears in the home page gallery with a lightbox viewer.

**Leistungen** — Edit service names and descriptions. Changes appear immediately in the accordion and on individual service pages.

**Hero-Text** — Change the main headline, subtitle and eyebrow text without touching code.

**Öffnungszeiten** — Add, edit or remove opening hours rows.

**Kontakt** — Update the address, phone, fax and email displayed across the site.

**Jobs** — Create job listings with structured sections. Toggle active or inactive.

## Built with

- **[Nuxt 3](https://nuxt.com)** — SSR framework with file-based routing
- **[Three.js](https://threejs.org)** — 3D hero canvas with scroll-driven camera animation
- **[Tailwind CSS](https://tailwindcss.com)** — utility styling with a full CSS variable theme system supporting dark and light mode
- **[Supabase](https://supabase.com)** — Postgres database, file storage and REST API
- **[DeepL API](https://www.deepl.com/pro-api)** — automatic translation pipeline for static and dynamic content
- **[Vercel](https://vercel.com)** — deployment
